这一页把主题自带的外挂标签集中演示一遍，写文章时直接抄。

## 1. 提示块 note

```markdown
{% note info flat %}说明文字{% endnote %}
```

{% note info flat %}info：普通提示{% endnote %}

{% note primary modern %}primary：主要提示{% endnote %}

{% note warning flat %}warning：警告提示{% endnote %}

## 2. 标签页 tabs

```markdown
{% tabs 分组名 %}
<!-- tab 第一个标签 -->
内容一
<!-- endtab -->
<!-- tab 第二个标签 -->
内容二
<!-- endtab -->
{% endtabs %}
```

{% tabs 演示 %}
<!-- tab 用 YAML 写 -->
```yaml
title: 示例
tags: [Hexo]
```
<!-- endtab -->
<!-- tab 用 JSON 写 -->
```json
{ "title": "示例", "tags": ["Hexo"] }
```
<!-- endtab -->
{% endtabs %}

## 3. 折叠 hideToggle

```markdown
{% hideToggle 点开看更多 %}
被折叠的内容
{% endhideToggle %}
```

{% hideToggle 点开看更多 %}
被折叠的内容，适合放答案、长代码或剧透。
{% endhideToggle %}
